## 🚀 Proyectos en producción

> El código de estos proyectos es privado (pertenece a la empresa); aquí describo lo que construí.

**CRM omnicanal integrado a ERP** — Ionic + Angular, ASP.NET Core, SignalR
- Bandeja de conversaciones de WhatsApp, Messenger e Instagram con asignación a agentes, casos, embudo comercial y calendario.
- Lo usan **10 empresas**; publicado como web y app Android en Google Play.

**Tiendas en línea conectadas al ERP** — Angular, APIs REST
- **5 tiendas** para clientes, sincronizadas con catálogo, inventario y facturación; pasarela de pago en línea.

**APIs REST de ERP** — NestJS + TypeScript
- Módulos de inventario, contabilidad, ventas, compras y planilla.
